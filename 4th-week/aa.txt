{
    1. 센서 융합 기반 위치 추정: 칼만 필터 (Kalman Filter)
개요

GPS 센서는 외부 환경의 간섭으로 인해 노이즈가 많아, 이를 그대로 사용하면 로봇의 위치 추정에 오차가 크게 발생한다. 이를 해결하기 위해 **칼만 필터(Kalman Filter)**를 이용해 시간에 따른 위치를 추정하였다.
핵심 구성

    상태 벡터: [pos_x, pos_y, vel_x, vel_y]

    예측 단계: 이전 상태와 속도를 기반으로 현재 위치 예측

    업데이트 단계: 실제 GPS 측정값과의 차이를 바탕으로 보정

    필터링 결과는 GPS 측정값보다 훨씬 부드럽고 현실적인 위치 추정 결과를 생성

적용 기술

    파이썬 NumPy 기반 선형 대수 연산

    칼만 필터 수식의 직접 구현 (예측, 업데이트 단계 수작업 코드화)

    2. 2-링크 로봇 팔의 기구학 및 자코비안 분석
Forward Kinematics

    주어진 관절 각도(θ1, θ2)와 링크 길이(l1, l2)를 이용해 손끝 위치 (x, y)를 계산

    로봇이 실제로 어떤 공간 위치에 도달할 수 있는지를 확인

Jacobian Matrix

    손끝의 속도와 관절의 속도 간 관계를 나타내는 자코비안 행렬을 수식 기반으로 구현

    자코비안의 역행렬은 로봇이 목표 위치로 이동하기 위해 각 관절을 얼마나 회전시켜야 하는지 계산하는 데 사용됨

⚠️ 3. 특이점(Singularity) 탐색 및 회피 제어
특이점 정의

    자코비안의 행렬식(det)이 0에 가까워지는 경우, 로봇이 특정 방향으로 움직이지 못하거나 무한한 속도를 요구하게 되는 비정상 상태 발생

    또는 condition number가 매우 커질 경우에도 수치적으로 불안정한 상태가 발생

판별 방법

    np.linalg.det(J) → det이 작으면 특이점으로 판단

    np.linalg.cond(J) → 수치적으로 특이점에 가까운 경우를 탐지

회피 알고리즘: Damped Least Squares (DLS)

    일반 역자코비안은 특이점 근처에서 폭주할 수 있음

    DLS 방식은 자코비안 역행렬 계산에 댐핑 요소를 더하여 안정성을 확보함
